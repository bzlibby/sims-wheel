# bzlibby's Sims Build Generator

This is a tool for generating a random build challenge for the Sims 4 with parameters such as world, budget, architectural style, and more. The generator is made so that it can be used by everyone from base game only players to pack completionists; just check off which pack(s) you own, press the generate button, and get to building!
